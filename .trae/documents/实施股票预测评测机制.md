# 实施股票预测评测机制

## 1. 后端：AI Service 集成 Langfuse
- 在 `ai_service` 中引入 `langfuse-go` SDK。
- 将现有的硬编码 Prompt 迁移到 Langfuse 管理。
- 在预测流程中添加 Tracing，记录输入、输出和元数据。

## 2. 后端：Stock Service 评测逻辑
- 创建 `prediction_evaluations` 数据库表，存储预测记录、目标价、实际收盘价和得分。
- 实现定时任务（Cron Job），在每日盘后获取 T+1, T+2, T+3 的股价。
- 自动计算预测准确率得分（基于偏差率）。
- 提供 API 供前端查询评测历史和统计数据。

## 3. 前端：Admin 管理后台
- 初始化一个新的 React 项目 `web_admin`。
- 实现评测列表页面，展示历史预测及其准确性。
- 实现详情页面，展示具体的 Prompt 版本、思维链（如果有）和股价走势对比。

该计划已在 `openspec/changes/add-prediction-evaluation` 中详细定义并通过验证。

## 技术面规则库（去重精炼版）

### 适用前提
- 必须结合市场环境（牛/熊/震荡）、板块热度（风口/退潮）、个股股性（流通盘/历史股性）综合判断
- 量能是验证走势真伪的核心，价格可被诱多/诱空，量能代表真实资金
- 单一形态不做结论，至少结合量能与市场环境二次确认

### 分时形态规则（形态 → 量能验证 → 可能含义 → 风险提示）
- 均价线上方横盘 → 缩量横盘、尾盘放量确认 → 主力控盘洗盘、等待拉升 → 板块无风口时易冲高回落
- 均价线下方横盘 → 温和放量、尾盘易跳水 → 托底出货或无承接 → 破位后下跌加速
- 均价线缠绕震荡 → 量能无规律忽大忽小 → 多空分歧、跟风走势 → 需等待板块或大盘方向
- 缓慢推升（价涨量增） → 拉升量大于回踩量、阶梯放量 → 资金分批进场、良性做多 → 若量能衰减则转为假突破
- 缓慢下跌（价跌量增） → 下跌放量、反抽缩量 → 资金有序离场、阴跌 → 易形成台阶式下跌
- 无量空涨 → 拉升缩量、均价线跟不上 → 诱多拉升 → 大概率冲高回落
- 无量急拉 → 瞬时拉升且量能不放大 → 诱多 → 回落风险高
- 放量急拉 → 大单持续买入、量能同步放大 → 真实拉升 → 若未突破关键压力则易回落
- 无量急跌 → 瞬时砸盘但无持续卖出 → 诱空洗盘 → 容易快速反抽
- 放量急跌 → 大单持续卖出、量能放大 → 真实出货 → 破位风险高
- 尾盘无量拉升 → 无量急拉 → 做收盘价诱多 → 次日低开风险
- 尾盘放量拉升 → 量能放大 → 抢筹或利好驱动 → 次日高开延续概率高
- 尾盘无量跳水 → 缩量下跌 → 做收盘价洗盘 → 次日不确定
- 尾盘放量跳水 → 放量下跌 → 利空或抢跑 → 次日低开低走风险
- 一字涨停 → 封单大且缩量封死 → 强势锁筹 → 开板放量需警惕出货
- 一字跌停 → 封单大且缩量封死 → 恐慌或利空 → 放量开板代表分歧
- 高开低走 → 高开后快速破均价线、下跌放量 → 高位出货 → 盘中反抽多为诱多
- 低开高走 → 低开后放量突破均价线 → 洗盘吸筹 → 板块无风口时仅为修复

### 关键辅助指标
- 量比 > 1.5 为放量，量比 < 0.8 为缩量，量比与股价同向为真实
- 换手率：小盘股 >15% 活跃、>20% 警惕出货；中盘股 >8% 活跃；大盘股 >3% 活跃

### 近 5 日 K 线与量价规则
- 价涨量增 → 多头趋势确认；价跌量缩 → 空头衰竭或修复信号；价量背离 → 反转风险
- 长上影线 → 上方压力强，需后续放量突破确认有效突破
- 长下影线 → 下方承接强，若后续跌破则支撑失效

### 多头组合（做多信号）
- 5 连阳（量能阶梯放大） → 量价同步 → 多头持续进场 → 无量大阳属诱多
- 阳包阴 → 放量反包 → 反转确认 → 次日若跌破阳线开盘价则失效
- 金针探底（长下影） → 探底缩量、拉升放量 → 支撑确认 → 后续跌破低点则失效
- 涨停后缩量小阳整理 → 量能缩、未破涨停开盘价 → 洗盘后拉升 → 破位即趋势转弱

### 空头组合（规避信号）
- 5 连阴（量能阶梯放大） → 价跌量增 → 空头持续 → 无量大阴为诱空
- 阴包阳 → 放量反包 → 顶部确认 → 反抽不破阴线开盘价
- 墓碑线（长上影） → 冲高放量回落 → 出货信号 → 后续无量反抽多为诱多

### 震荡组合
- 箱体震荡 → 量能忽大忽小 → 等待放量突破方向 → 破位需降仓
- 影线密集 → 试盘期 → 放量突破影线高点确认方向 → 反向破位风险高

### 冲突与不确定性处理
- 分时与 K 线结论冲突时，降低置信度并说明冲突点
- 量能与价格背离时，以量能为主判定
- 市场环境与形态信号冲突时，以环境为主调整结论强度

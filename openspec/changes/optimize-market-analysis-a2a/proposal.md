# Proposal: 引入 A2A 架构优化盘前分析推荐逻辑

## 1. 背景 (Context)
当前的“盘前分析”功能直接依赖 Analyst Agent (LLM) 根据市场数据生成推荐股票。虽然 LLM 具备一定的逻辑分析能力，但在缺乏深度定量数据（如分形历史匹配、实时资金流向的深度计算）支持的情况下，容易产生“幻觉”或推荐基本面/技术面不佳的股票。
我们已经拥有一个专门的 Predictor Agent，它集成了分形算法、技术指标和资金面分析，能够提供更严谨的个股预测。

## 2. 目标 (Goals)
通过 Agent-to-Agent (A2A) 协作模式，提升盘前分析推荐股票的质量和胜率。
- **初筛**: Analyst Agent 负责从宏观板块和市场情绪中筛选出较多数量的“潜力股”。
- **精选**: Predictor Agent 对潜力股进行深度体检。
- **决策**: 基于预测结果（趋势、置信度）进行最终过滤和排序。

## 3. 变更范围 (Scope)
- **AI Service**:
  - 修改 `MarketAnalysisMaster` 提示词，要求输出更多候选股（6只）。
  - 修改 `AnalyzeMarket` 处理逻辑，增加 A2A 编排层。
  - 集成 `Predictor` 的验证结果。

## 4. 详细设计 (Detailed Design)

### 4.1 流程图
```mermaid
graph TD
    A[用户请求盘前分析] --> B[Analyst Agent: 市场分析]
    B -->|产出| C[初筛池 (6只股票)]
    C --> D{并发验证}
    D -->|Stock 1| E[Predictor Agent]
    D -->|Stock 2| E
    D -->|...| E
    E -->|产出| F[预测结果 (趋势/置信度)]
    F --> G[过滤器]
    G -->|规则: 看涨 & 置信度>0.6| H[最终推荐列表]
    H -->|Top 3| I[返回给用户]
```

### 4.2 提示词变更
修改 `MarketAnalysisMaster`，明确指示 LLM 生成 6 只股票作为初筛池，并保持原有的低位/启动逻辑。

### 4.3 编排逻辑
在 `handler.go` 中：
1. 调用 Analyst 获取 6 只候选股。
2. 并发调用 Predictor 对每只股票进行 `Predict`。
3. 收集结果，优先保留“看涨”且置信度高的股票。
4. 如果合格股票不足 3 只，按置信度排序补充“中性”股票，剔除“看跌”股票。
5. 最终返回 3 只（或更少）高质量推荐。
